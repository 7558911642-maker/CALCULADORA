PARA PROBAR:
1. Abre la carpeta en VS Code.
2. Usa Live Server sobre index.html.
3. No abras index.html con doble clic si quieres probar correctamente el service worker.

PARA INSTALAR EN EL CELULAR:
Debes publicar esta carpeta completa por HTTPS (GitHub Pages, Netlify, Vercel, hosting propio, etc.).
