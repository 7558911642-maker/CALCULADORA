Uso rápido

El flujo principal está pensado para trabajar cómodamente desde un celular.

1. Registra o edita terrenos

Manzana, lote, área, frente, fondo, ubicación, estado, precio y planes.

2. Abre Calculadora

Selecciona un terreno, define inicial y plazo, y revisa la cuota mensual.

3. Guarda la cotización

Asóciala a un cliente y consérvala en el historial del teléfono.

4. Haz respaldo

Descarga un JSON para recuperar tus datos si cambias o borras la app.

Instalación

Cuando la aplicación esté publicada por HTTPS podrá instalarse como PWA.

Android / Chrome

Usa el botón “Instalar app” cuando aparezca, o menú ⋮ → “Instalar aplicación”.

iPhone / Safari

Compartir → “Añadir a pantalla de inicio”. iOS no siempre muestra un botón automático de instalación.
